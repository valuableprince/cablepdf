# СКП — Сверка кабелей и проходок

Windows-программа для двусторонней сверки обозначений кабелей в двух PDF с **извлекаемым текстовым слоем**. Сканы без текста (OCR) не поддерживаются.

## Готовый Windows EXE

1. Откройте **Actions → Build CablePDFCompare Windows EXE**.
2. Откройте успешный запуск.
3. Скачайте артефакт **SKP_CableCompare-v0.8-beta-Windows-x64**.
4. Распакуйте ZIP и запустите `SKP_CableCompare.exe`.

Это автономный exe без установки Python (Windows 10/11 x64). В сборке применяется иконка `CablePDFCompare.ico`.

## Что внутри репозитория

- `source/SKP_CableCompare_v0.8_Beta_Source_WindowsBuild.zip` — исходники версии 0.8 beta и тесты.
- `.github/workflows/build-windows-exe.yml` — автоматическое тестирование и сборка через GitHub Actions.

Версия 0.8 beta **не является окончательной реализацией ТЗ 1.0**: сложные привязки к физическим проходкам требуют ручной проверки.

Проект использует PyMuPDF, Pillow, openpyxl и PyInstaller. Перед корпоративным распространением проверьте соответствие лицензированию PyMuPDF и других зависимостей.

## Контроль качества

CI запускает автоматические тесты, затем собирает `--onefile --windowed` exe. Проверка интерфейса на реальном рабочем ПК остаётся отдельным этапом приёмки.
